# AI Agent Notes

## Overview

This repository contains tutorials for learning how to build AI Agents using tools like LangChain, LangGraph, and external APIs.

AI agents are systems that can understand user queries, reason about problems, use tools when needed, and generate useful responses.

- ```LangChain``` – A framework that helps developers build AI applications by connecting LLMs with tools, prompts, and data.

- ```LangGraph``` – A framework used to create multi-step AI workflows where agents can reason and perform tasks step by step.

- ```MCP``` (Model Context Protocol) – A standard that allows AI models to connect and communicate with external tools and services.
## Goal

The goal of this tutorial is to understand how AI agents work and how to build practical AI-powered applications step by step.
